
# Manejo de Presupuesto 💰

**Manejo de Presupuesto** es una aplicación web desarrollada para la gestión de finanzas personales. Su objetivo es permitir a los usuarios registrar y visualizar sus movimientos financieros de manera sencilla. El proyecto fue construido utilizando **C#** y sigue el patrón de diseño **MVC (Model-View-Controller)**.

---

## Funcionalidades Implementadas ✨

* **Gestión de Transacciones:** Registro de ingresos, gastos, categorías y cuentas.
* **Visualización de Datos:** Permite ver los datos financieros en vistas diarias, semanales y mensuales.
* **Sistema de Usuarios:** Incluye un módulo de autenticación para usuarios, con funciones de registro, inicio de sesión y recuperación de contraseña por correo electrónico (Gmail).
* **Exportación de Datos:** Funcionalidad para exportar transacciones a un archivo **Excel**.
* **Calendario:** Vista integrada para visualizar las transacciones por fecha.
